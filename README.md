# Aura Frames for Home Assistant

Unofficial Home Assistant custom integration for Aura Frames through the reverse-engineered PUSHD API.

## Installation

Add `Reaper2507/ha-aura-frames` as a custom HACS integration repository, download it, restart Home Assistant, and add **Aura Frames** under Settings -> Devices & services.

The integration stores the account in Home Assistant's config-entry storage. Credentials are not part of this repository.
